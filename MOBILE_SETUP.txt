Pokemon: Synthesis — Android Setup Guide (JoiPlay)
===================================================

Pokemon: Synthesis can be played on Android using JoiPlay, a free app
that runs RPG Maker games on mobile devices.


WHAT YOU NEED
-------------
1. An Android phone (Android 8.0+)
2. This game package (PokemonSynthesis_Mobile.zip)
3. JoiPlay app + RPG Maker XP plugin (both free on the Play Store)


CREATING THE ZIP (on your desktop)
----------------------------------
If you already have Pokemon: Synthesis running on your computer
(i.e. you've already run play.bat or build_and_launch.sh and the
game works), you can create the mobile package in one step:

  Windows (Git Bash):
    ./build_and_launch.sh --mobile

  Linux / macOS:
    ./build_and_launch.sh --mobile

This will produce a file called PokemonSynthesis_Mobile.zip in the
project folder. It uses your already-injected game data, so it only
takes a few seconds.

If you haven't set up the game yet, --mobile will do that for you
automatically (clone the game data and inject the Synthesis dialogue)
before creating the ZIP.

NOTE FOR WINDOWS USERS: If you used play.bat to set up the game
originally, you'll need Git Bash to run the --mobile command. Git
Bash was installed as part of the play.bat setup — you can find it
in your Start menu. Open it, navigate to the project folder
(cd /c/path/to/pkmnSynthesis), and run the command above.


STEP 1: Install JoiPlay (on your phone)
------------------------
- Open the Google Play Store on your phone
- Search for "JoiPlay" and install it
- Search for "JoiPlay RPG Maker Plugin" and install that too
  (this is a separate app that adds RPG Maker XP support)


STEP 2: Get the ZIP onto your phone
------------------------------------
The easiest way: email PokemonSynthesis_Mobile.zip to yourself, open
the email on your phone, and download the attachment. It will land in
your Downloads folder, which is fine.

Then extract it:
- Install "ZArchiver" from the Play Store (free, no ads)
- Open ZArchiver and navigate to Downloads
- Tap PokemonSynthesis_Mobile.zip and choose "Extract here"
- You should now have a PokemonSynthesis_Mobile folder in Downloads

That's it. The extracted folder just needs to stay on your phone's
local storage. If the game won't launch, the most likely cause is
Google Drive syncing your Downloads folder — see Troubleshooting below.


STEP 3: Configure the RPG Maker XP Plugin
------------------------------------------
This step is REQUIRED or the game will crash on launch.

- Open JoiPlay
- Tap the gear icon (Settings) in the top right
- Tap "RPG Maker XP" (the plugin settings)
- Find the option "Use Ruby 1.8" and make sure it is OFF (disabled)
  (The mobile build is patched for Ruby 1.9. If "Use Ruby 1.8" is ON,
   the game will crash with script errors.)
- Go back to the main screen


STEP 4: Add the game in JoiPlay
-------------------------------
- Open JoiPlay
- Tap the "+" button to add a new game
- Fill in:
    Name:       Pokemon: Synthesis
    Executable: (browse to the extracted folder and select Game.exe)
    Game Folder: (should auto-fill to the extracted folder)
- Tap the checkmark to save


STEP 5: Play!
-------------
- Tap "Pokemon: Synthesis" in JoiPlay's game list
- The game should launch. First load may take a moment.


TROUBLESHOOTING
---------------

"Game crashes on launch"
  - Make sure you installed the RPG Maker XP plugin (not just JoiPlay)
  - Make sure the game is on internal storage, not cloud/SD
  - If the error mentions "NoMethodError" or "undefined method", the
    mobile package may need to be rebuilt with the latest patcher fixes.
    Re-run ./build_and_launch.sh --mobile on your computer and transfer
    the new ZIP to your phone.

"Script error: NoMethodError / undefined method"
  - First, make sure "Use Ruby 1.8" is OFF in JoiPlay's RPG Maker XP
    plugin settings (see Step 3 above). This is the most common cause.
  - If the setting is correct, this means a Ruby compatibility issue
    slipped through the patcher. Note the script name and line number.
  - Rebuild the mobile package (./build_and_launch.sh --mobile) — the
    patcher is regularly updated to fix these issues.
  - If the error persists after rebuilding, report it as an issue with
    the exact error text.

"Black screen or missing graphics"
  - Check that the Graphics/ folder was fully extracted
  - Try re-extracting the ZIP with a different app (ZArchiver works well)

"Audio doesn't play"
  - Check that the Audio/ folder was fully extracted
  - Some audio formats may not work on all devices — this is a JoiPlay
    limitation, not a game issue

"Game is slow"
  - In JoiPlay settings, try lowering the rendering resolution
  - Close other apps running in the background

"Google Drive keeps uploading game files"
  - Move the game folder out of any Drive-synced directory
  - On Pixel phones: Settings > Google > Backup > turn off "Google Drive"
    for the file manager, or simply use a folder that isn't synced


NOTES
-----
- Save files are stored in the game folder. If you move the game,
  copy your save files too.
- This package already includes the Synthesis mod dialogue. You do
  NOT need to run any injection scripts on your phone.
- JoiPlay is a third-party app and is not affiliated with this project.
